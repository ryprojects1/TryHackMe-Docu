Windows Command Line part 1
Why CLI is better than GUI?
- speed
- efficiency
- lower resource usuage
- automation
- remote management
  Ver, show version
  systeminfo, list various info about system such as OS info, system details, processor and memory
  Network Troubleshooting
  ipconfig, show the network info
  ipconfig /all show more detailed network info
  ping (target_name), check wheter connection can be made
  tracert, show the path your data takes to reach a destination
  nslookup, looks up a host or domain and return into IP address
  netstat, display current network connections and listening ports
  netstat -abon, more detailed
  dir, show child directories
  dir /a, show hidden child
  copy, allow you to copy files from one location tp another
  tasklist, show running process
